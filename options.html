設定

YouTube Data API キー

キーはこのブラウザ内にだけ保存されます。取得手順は 公式ドキュメント を参照してください（YouTube Data API v3 を有効にし、キーの API 制限もそれだけにするのがおすすめです）。

番組表

番組表は自動で作られ、毎日ランダムに組み替わります（時間帯の区切りもジャンルも国も、手動では選べません）。 1 日を 4〜8 の枠に分け、枠ごとに「ジャンル 1 つ ＋ 国 3 か国」を割り当てます。 ジャンルは同じ日に重ならず、国は選んだ国を並べ替えた山から順に配るので、どれも偏りません。

オフにすると、枠を作らず、毎回「ジャンルを等確率で選ぶ → 選んだ国を等確率で選ぶ」で流します。

流す国

選べるのは国だけです。動画やジャンルは選べません。番組表はここで選んだ国の中から組まれ、変更は次の動画から反映されます。
