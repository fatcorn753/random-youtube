# ランダムYoutube

YouTube をテレビのように見るための Chrome 拡張です。

おすすめや検索で動画を選ぶ代わりに、各国の「人気の動画」からランダムに選んで流し続けます。
動画を選ぶことはできません（「次へ」でスキップはできます）。視聴の偏りをなくすための道具です。

## 特徴

- 選べるのは **国だけ**。国は全選択・全解除・大陸ごとの一括指定ができます。動画とジャンルは選べません
- **ジャンルの偏りをなくします。** YouTube の人気一覧をそのまま使うと音楽とゲームが大半を占めるため、ジャンルを先に等確率で選び、そのジャンルの人気動画から選びます（12 ジャンル）
- 選んだ国を **等しい確率** で抽選します（動画の多い国に偏りません）
- **番組表は自動で、毎日ランダムに組み替わります。** 時間帯の区切り・ジャンル・国は手動では選べません
- 一度見た動画は、その一覧を見尽くすまで再び出ません
- Shorts、ライブ、埋め込み不可の動画は流しません
- ポップアップで、今日の番組表、今日見た本数、ジャンル別・国別の分布を確認でき、国をすぐ切り替えられます（変更は次の動画から反映されます）

## 番組表のしくみ

- 1 日を 4〜8 の枠に分けます。枠は最短 60 分で、境界は一様にランダムに決まります
- 枠ごとに **ジャンル 1 つ ＋ 国 3 か国** を割り当てます
  - ジャンルは、並べ替えた 12 ジャンルから順に割り当てるので、同じ日に同じジャンルは重なりません
  - 国は、選んだ国を並べ替えた 1 つの山から順に配るので、1 日のうちどの国もほぼ同じ回数だけ当たります
- 日付が替わると、新しい番組表が作られます。保存するのは「日付と乱数の種」だけで、番組表はそこから再現します
- 選んだ国を変えると、番組表の国も次の動画からすぐ入れ替わります
- 枠に当てはまる動画が見つからないときは、止まらないよう、その動画だけ全ジャンル・選んだ国から選びます
- 詳細設定で番組表をオフにすると、枠を作らず、毎回「ジャンルを等確率で選ぶ → 国を等確率で選ぶ」で流します

### ジャンルについて

YouTube の人気チャートが存在する 12 ジャンル（映画・アニメ、自動車・乗り物、音楽、ペット・動物、スポーツ、ゲーム、ブログ・日常、コメディー、エンタメ、ニュース・政治、ハウツー・スタイル、科学・技術）を使います。
「旅行とイベント」と「教育」はチャートが無いので含まれません。
また、小さな国の「ブログ・日常」など、人気動画が 10 本に満たない一覧は使いません。選んだ国が少ないと、そのジャンルが出ないことがあります。

## インストール

1. このリポジトリをクローンまたはダウンロードします
2. `chrome://extensions` を開き、「デベロッパーモード」をオンにします
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選びます

## 使い方

1. [YouTube Data API v3 のキー](https://developers.google.com/youtube/v3/getting-started) を取得します
   （Google Cloud でプロジェクトを作り、YouTube Data API v3 を有効にします。キーの API 制限もそれだけにすると安全です）
2. 拡張のアイコンを開き、「詳細設定」からキーを入力して「保存して確認」を押します（キーはこのブラウザ内にだけ保存され、入力は 1 回だけです）
3. 流す国を選びます（初期値はブラウザの言語の国です）。ポップアップでは大陸ごとの一括指定と全選択・全解除、詳細設定では国名検索つきの一覧で選べます。国を多く選ぶほど、ジャンルが揃いやすくなります
4. ポップアップの「視聴画面を開く」から「放送開始」を押します

### 今日見た本数

動画の再生が始まった時点で 1 本と数えます（広告が流れているあいだは数えません）。
保存するのは日付ごとの本数と、国別・ジャンル別の本数だけで、動画の中身は保存しません。直近 30 日分を残します。

API の割り当ては 1 日 1 万ユニットです。この拡張は「国 × ジャンル」の一覧ごとに 1 時間に 1 ユニットしか使わず、普通の使い方では 1 日に数十ユニット程度です。

## 仕組み

- 動画の一覧は YouTube Data API の `videos.list`（`chart=mostPopular` に国とジャンル `videoCategoryId` を指定）で取得します
- `chrome-extension://` から YouTube を直接埋め込むと「エラー 153」で再生できないため、
  再生は GitHub Pages 上の小さなページ（`docs/player.html`）を iframe で開いて行います。
  拡張とはメッセージのやり取りだけをします。
  フォークして使う場合は、自分の Pages を有効にして `src/config.js` の `PLAYER_URL` を変更してください

## 限界

- 再生中の YouTube プレイヤーから YouTube 本体へ移動できてしまいます。自分を律するための道具で、強制する仕組みではありません
- YouTube の公式プレイヤーをそのまま使うので、広告は表示されます（広告のあいだは再生開始とみなさないため、本数にも数えません）
