# ランダムYoutube

YouTube をテレビのように見るための Chrome 拡張です。

おすすめや検索で動画を選ぶ代わりに、各国の「人気の動画」からランダムに選んで流し続けます。
動画を選ぶことはできません（「次へ」でスキップはできます）。視聴の偏りをなくすための道具です。

## 特徴

- 選べるのは **国だけ**。国は全選択・全解除・大陸ごとの一括指定ができます
- 選んだ国を **等しい確率** で抽選します（動画の多い国に偏りません）
- 一度見た動画は、その国の人気一覧を見尽くすまで再び出ません
- Shorts、ライブ、埋め込み不可の動画は流しません

## インストール

1. このリポジトリをクローンまたはダウンロードします
2. `chrome://extensions` を開き、「デベロッパーモード」をオンにします
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選びます

## 使い方

1. [YouTube Data API v3 のキー](https://developers.google.com/youtube/v3/getting-started) を取得します
   （Google Cloud でプロジェクトを作り、YouTube Data API v3 を有効にします。キーの API 制限もそれだけにすると安全です）
2. 拡張のアイコンを開き、「設定」からキーを入力して「保存して確認」を押します（キーはこのブラウザ内にだけ保存されます）
3. 流す国を選びます（初期値はブラウザの言語の国です）
4. 「放送開始」を押します

API の割り当ては 1 日 1 万ユニットで、この拡張は国ごとに 1 時間に 1 ユニットしか使いません。

## 仕組み

- 動画の一覧は YouTube Data API の `videos.list`（`chart=mostPopular`）で取得します
- `chrome-extension://` から YouTube を直接埋め込むと「エラー 153」で再生できないため、
  再生は GitHub Pages 上の小さなページ（`docs/player.html`）を iframe で開いて行います。
  拡張とはメッセージのやり取りだけをします。
  フォークして使う場合は、自分の Pages を有効にして `src/config.js` の `PLAYER_URL` を変更してください

## 限界

- 再生中の YouTube プレイヤーから YouTube 本体へ移動できてしまいます。自分を律するための道具で、強制する仕組みではありません
- YouTube の公式プレイヤーをそのまま使うので、広告は表示されます
